# Python Quest

The project now includes a React + TypeScript web app.

## Run the React app

```powershell
cd .\web
npm install
npm run dev
```

Then open `http://localhost:5173`.

## Legacy apps
- Tkinter desktop app remains in `python_quest.py`
- Flask version remains in `app.py` (not used by the React app)

## Run tests (Python engine)

```powershell
python -m unittest .\tests\test_tasks.py
```
